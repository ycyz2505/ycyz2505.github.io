# 杨村一中电子班牌

面向班级希沃一体机展示的静态网页，包含班级信息、作息课表、高考倒计时、二十四节气、金句轮播、每日 60 秒新闻简报、公告、通知、寻物、计算器、音乐播放器、虚拟时间、座位表、广场等功能。以 1920×1080 为设计基准，自适应缩放到不同分辨率。

## 技术栈

纯 HTML + CSS + JavaScript，本地存储使用 json（由本地服务读写磁盘）。广场的密码与私密字段用 WebCrypto 做 PBKDF2 + AES-256-GCM 加密。

## 快速开始

直接双击 `index.html` 即可打开。此模式下：

- 所有展示功能正常；
- 修改不会被保存；
- 右上角提示“本地服务未启动”。

考虑到 C 盘会还原，因此本地数据未使用浏览器缓存进行存储，而是由位于 D 盘的 `LocalDataServer.exe` 进行中转，实现网页直接读写本地磁盘。请先运行该文件，再打开页面。页面会自动探测本地端口 `17632` 到 `17641`。

> `LocalDataServer.exe` 和 `m-server.exe` 都可以从 [Releases](https://github.com/ycyz2505/ycyz2505.github.io/releases/tag/build-latest) 下载，放到同一个目录里即可。

音乐功能还需要在 `LocalDataServer.exe` 同级目录下建立 `data\music\` 文件夹，把歌曲按子文件夹分类放进去（同目录内可放 `.lrc` 歌词与封面图，封面优先匹配 `cover`、`folder`、`front`、`album`、`封面` 等命名，否则将使用文件夹内第一张图片）。

## 功能一览

**展示**：时间日期、天气（当前温度，位于日期下方）、当前作息、下个作息倒计时、今日课表（已过去的课变灰、正在进行的课高亮）、高考倒计时、节气时间轴、每日 60 秒、金句轮播。

**交互**：设置、金句选择、公告、更新日志、通知、寻物、今日课表临时编辑、虚拟时间、计算器、音乐播放器、座位表、广场、个人空间、名单管理、模态框全屏、模态框定时关闭。

## 音乐播放器

在计算器中连续输入某暗码即可打开音乐播放器。暗码在 `js/features/m_player.js` 中的 `SECRET_CODE` 常量里修改。

播放器顶部有 **本地 / 搜索 / 歌单** 三个标签页。本地页就是原来那套目录树；搜索和歌单页需要额外的本地伴生服务 `m-server.exe`（见下一节），没有它这两个标签页会提示"本地服务未启动"。

- 歌曲来源为 `data\music\` 目录，通过 `LocalDataServer.exe` 读取；
- 歌曲列表保留原始目录层级，以树形结构展示，可折叠展开，分类文件夹右侧显示歌曲数量；
- 自动识别歌曲文件夹内的图片作为封面（优先匹配 `cover`、`folder`、`front`、`album`、`封面` 等命名），无封面时以 ♪ 字符兜底；
- 支持逐行与逐字两种 LRC 格式；
- 播放时把当前歌词同步显示到首页金句位置，暂停或停止后恢复原金句轮播；音乐接管金句期间，点击刷新与自动轮播暂时挂起；
- 无歌词文件时播放条显示“歌词缺失”，金句区不被接管、继续轮播；
- 播放模式：顺序 / 列表循环 / 单曲循环 / 随机，点击循环按钮切换；
- 音量条可拖动，音量图标可点击静音/恢复上次音量；
- 首页按钮区最右侧的“⏹ 关闭”按钮仅在选中歌曲时显示，点击即可停止播放、清空当前歌曲并恢复金句轮播。

**播放器设置面板**（点击右下角 ⚙ 打开）：

- **定时关闭**：可选 5/10/15/30 分钟、1 小时预设，或自定义秒数、指定时刻到点关闭；
- **输出设备**：列出当前系统的音频输出设备，可逐台启用/禁用。该操作需要以管理员身份运行 `LocalDataServer.exe`；
- **音源分配**：音频 / 歌词 / 封面可以分别指定来源；
- **隐蔽控制**：是否显示首页「关闭」按钮；停止快捷键（点一下输入框再按任意键即可录制，默认 `Esc`）。

**隐蔽操作**（只在播放中生效，触发前后没有任何提示）

| 操作 | 效果 |
|---|---|
| 点节气时间轴**最左边**的节气 | 上一首 |
| 点节气时间轴**最右边**的节气 | 下一首 |
| 点**其余任意**节气 | 停止播放（与「关闭」按钮一致） |
| 按停止快捷键 | 停止播放 |
| 任意位置滚动滚轮 | 调整**系统音量**；滚动时「下个作息倒计时」的数字临时显示当前音量，停手 0.5 秒后自动恢复 |

> 滚轮走的是 Windows 主音量（`LocalDataServer.exe` 的 `/api/audio/volume`），不是网页里那根音量条。如果本地服务版本太旧没有这个接口，会自动退回调整播放器自身音量。

## 在线搜索与本地歌单

这两块需要额外的本地伴生服务 `m-server.exe`（源码在 `m-server/`，从 Releases 下载，**不需要安装任何运行时**）。把它和 `LocalDataServer.exe` 放在同一目录、双击运行即可，端口从 `17650` 开始自动找，页面会自己探测。

它是**静默启动**的，双击后不会弹命令行窗口，也没有托盘图标。日志写在同目录的 `m-server.log`（超过 4MB 转存为 `.old`），排查问题时可以先设 `M_LOG=debug` 再启动一次。停止方式：任务管理器结束 `m-server.exe`，或 `taskkill /IM m-server.exe /F`。

**搜索页**

- 输入关键词后并发搜索多个音源（默认网易云、QQ、酷狗、酷我、千千；咪咕、汽水、B站可在音源标签里手动打开）
- 每条结果带音源标记、时长、封面，点 ▶ 直接试听，点 ＋ 加入当前选中的歌单
- 试听是**纯流式**的：音频不落盘，只在内存里中转，切歌即释放；封面和歌词同样只在内存缓存

**歌单页**

- 新建 / 改名 / 删除歌单，移出单曲，一键体检
- 「加入歌单」会把音频、封面、歌词三个文件下载到 `data/m/<歌单名>/<歌名 - 歌手>/`，每首歌一个子文件夹，封面和歌词不会互相串
- 歌单里的歌可以直接播，不需要联网

**质量校验与换源**

播放前和下载前都会做三级校验：

| 对象 | 检查内容 |
|------|----------|
| 音频 | 魔数（ID3 / fLaC / OggS / ftyp / RIFF / WMA）、是否误返回网页或 JSON、码率与标称时长是否匹配（用于识别 30 秒试听片段） |
| 歌词 | 是否为空、有没有 `[mm:ss]` 时间轴、有效行数是否过少、是否误返回网页、非 UTF-8 自动按 GBK 解码 |
| 封面 | 魔数、文件大小、能否解码、尺寸是否过小 |

综合评分（100 分制）：音频不合格直接否决，歌词缺失 −25，封面缺失 −10，时长明显不符 −45。

- **≥ 70**：直接用
- **45 ~ 69**：先换源试一次，换不到更好的就用它，并在界面上标出问题
- **< 45**：强制换源；所有源都不行就选分最高的，明确提示"音质较低 / 歌词缺失"

播放过程中如果出错或卡顿，会自动换一次源并尽量保持播放进度。

> 版权提示：通过该功能获取的音频、歌词、封面版权归各平台与权利人所有，仅供个人学习使用，请勿公开部署为下载服务。`m-server/` 目录适用 AGPL-3.0（详见其 `LICENSE` 与 `NOTICE`）。

**音源分配（音频 / 歌词 / 封面分开选源）**

播放器设置面板里新增了「音源分配」，三行下拉分别指定**音频、歌词、封面**从哪个平台取，例如音频用 B 站、歌词和封面用咪咕。选「自动」表示跟随音频源，也就是原来的行为。

- 音频源一旦指定，就不再自动换源（否则等于没指定）；找不到可用音频会直接报错
- 歌词 / 封面指定了别的源时，会按「歌名 + 歌手 + 时长」在该源里找最匹配的一首，相似度低于 0.55 就回退到原源，不会硬凑
- 匹配结果缓存 15 分钟，同一首歌重复播放不会反复搜索
- 配置存在 `data/m/prefs.json`，也可以直接改文件
- 歌单里每首歌的质量数字，鼠标悬停会显示这首的音频 / 歌词 / 封面各自来自哪个源

**网络自适应（80 端口被拦时自动换路）**

有些校园网只放行 443、掐掉 80，而酷狗 / 酷我的接口是明文 HTTP，就会表现为「超时 / 连接被重置 / 返回空」。`m-server` 启动后先自检 IPv6、DNS、本地代理，再据此生成一条自动降级链：

```
direct → direct+https → dns → dns+https → nokeep → proxy
```

- 某条路走通后会按域名记住 10 分钟，之后直接走它，不再试错
- 全部失败会把该域名熔断 90 秒，避免每次搜索都白等
- 响应会被嗅探：空响应、返回网页而不是接口数据、5xx，都算失败并继续换下一条路
- 本机开着 Clash / v2ray 之类代理时会被自动发现并纳入兜底
- 自检结论写在 `m-server.log`，也可以 `GET /api/m/net` 查看当前每个域名在用哪条策略
- 需要强制指定时仍可用 `M_FORCE_IPV4=1`、`M_DNS=223.5.5.5`、`M_PROXY`，或写 `data/m/proxy.json`

## 座位表

首页按钮区的“🪑 座位表”打开，含 **展示 / 编辑** 两种模式（标题栏右侧 ⛶ 可全屏）。页面分成左右两栏：**左边是座位区**（宽度只随模态框 / 窗口变化，打开面板、切换模式都不会移动），**右边是控制区**（模式切换、搜索、随机抽取、编辑工具、积木盒、快速生成与 CSV 面板）。屏幕上方是教室前侧（黑板 / 讲台），下方是教室后侧。

座位表是一张**固定的格子表**：位置从一开始就存在，编辑模式下每个空位显示一个“待决定”的虚框（展示模式下只显示人名块与讲台块，空位与过道保持占位但不再显示边框），往后你只需要决定每个位置放什么。全表共用同一个“每行格数”（编辑模式里可以 +/- 调整）。

### 三种块（积木）

| 块 | 占格 | 说明 |
|----|------|------|
| 人名块 | 横向 2 格 | 显示一个人名 |
| 过道块 | 1 格 | 两组座位之间的空当，展示模式下为纯空白 |
| 讲台块 | 横向 2 格 | 深色底、显示“讲台”，**位置任意**，放哪都行 |

### 编辑（积木盒拖放）

- **添加**：编辑模式右侧有“🧱 积木盒”，按住人名块 / 过道块 / 讲台块直接拖到左侧格子里；拖动过程中左侧会高亮将要放下的位置，放不下（没有连续空位）时不会落下；
- **拖动**：已放好的块也可以按住拖动、跨行移动；拖动中按 `Esc` 取消；
- **改名**：点击人名块就地输入，回车或点击别处保存，`Esc` 取消；
- **删除**：块右上角 `×` 把它变回“待决定”的空位；每行末尾的 `↑` `↓` `🗑` 可以整行上移 / 下移 / 删除；
- **每行格数**：工具条里的步进器全局增减列数（右侧还有块时会提示先挪走）；
- **工具条**：`＋ 添加行`（整行都是待决定空位）、`⚡ 快速生成`（按“行数 × 每行人数 × 每几人有条过道”批量生成空表，可选顶部加讲台）、`📄 CSV 导入 / 导出`、`🗑 清空`。

### CSV 导入 / 导出

一行 CSV = 座位表的一行，**第一行在教室最前方**（讲台一侧）；字段之间用英文逗号分隔（也支持中文逗号、制表符，可直接从 Excel / WPS 复制粘贴）。

| 写法 | 含义 |
|------|------|
| `张三` | 人名块（横向 2 格） |
| `-` | 过道块（1 格） |
| `讲台` | 讲台块（横向 2 格） |
| 空字段 | **待决定的空位**（1 格） |
| `_` | 空人名块（横向 2 格，还没有名字的座位） |
| `# 开头的行` | 注释，导入时忽略 |

```csv
# 示例：第一行讲台居中，下面一行 6 人、中间留一条过道
# 空字段 = 待决定的空位
,,,,,讲台,,,,,,
张三,李四,王五,-,赵六,钱七,周九
```

模态框进入“编辑”模式后点“📄 CSV 导入 / 导出”即可看到同样的教程与示例：可直接在文本框里编辑后导入、选择 `.csv` 文件导入、复制当前座位表、或下载 CSV（导出带 BOM，Excel 打开不乱码，文件名形如 `座位表-20261004-1536.csv`）。导入会自动替换当前座位表并把各行对齐到统一格数。

### 人名搜索

在展示模式的搜索框里每输入一个字符就即时高亮所有匹配的人名块，不需要按回车；右侧提示匹配人数。

- 中文前缀：输入 `车一` 可匹配“车一诺”；
- 拼音首字母：输入 `cyn` 可匹配“车一诺”，也支持混输（如 `车yn`）；
- 多音字（车、单、曾等）按全部读音匹配；
- 回车可滚动定位到第一个结果（并闪一下），`Esc` 或搜索框右侧 ✕ 清空。

### 随机抽人

点击“🎲 随机抽取”后连续随机高亮单人，**两次高亮的间隔先快后慢、依次拉长**（约 45ms → 300ms），**总时长 6 秒**；最后一次高亮的人就是抽取结果，随后弹出大号渐变姓名卡片（彩带 + 弹入动画），可“🔁 再抽一次”或“完成”；被抽中的座位在座位表中脉冲高亮，关闭弹窗后清除，抽取过程中按 `Esc` 可取消。

### 数据存储

座位表数据保存在 `data/settings.json` 的 `settings.seating` 字段，形如：

```json
{ "version": 2, "cols": 6, "rows": [[null, null, { "t": "p" }, { "t": "s" }, null, null], [{ "t": "n", "n": "张三" }, { "t": "s" }, { "t": "a" }, { "t": "n", "n": "李四" }, { "t": "s" }, null]] }
```

`cols` 是每行格数；每行是由格子组成的数组，格子取值：`null` 待决定的空位、人名块 `n`（占 2 格）、过道块 `a`、讲台块 `p`（占 2 格）、续格 `s`（2 格块的第二格，渲染时被块覆盖）。旧版（`version: 1`）的数据会在打开时自动迁移成这种格式。每次编辑操作都会自动写入本地；`js/data/pinyin.js`（汉字 → 拼音首字母表）随站点一起分发，搜索与抽取全部离线可用。

## 广场 / 个人空间

首页按钮区的「🏛 广场」打开。广场是全班同学的名片墙：每人一张卡片，卡片上有背景图、头像、昵称、真实姓名、性别、学号、生日、个性签名、个人介绍、关注数、粉丝数和点赞量，右下角是关注按钮。**浏览不需要登录，关注、点赞、进自己的空间需要登录。**

> 这一套是按「全班共用教室一体机、同学们轮流走到班牌前登录」设计的。`LocalDataServer` 只监听 `127.0.0.1`，所以它天然只能在一台机器上用——同学们各自用手机打开是没法共享数据的。

### 名单管理（先做这一步）

第一次用之前，要到 **设置 → 名单管理** 里录入同学名单。入口需要**管理员密码**（首次进入时设置，8–32 位，同样是密文存本地、同样支持防偷窥的包含式输入；关闭名单管理即失效）。

- **📄 从座位表导入**：把「🪑 座位表」里已经排好的人名一键搬过来，同名自动跳过。50 个人一步到位。
- **CSV 导入 / 导出**：字段是 `学号,真实姓名,性别,昵称,初始密码`，和座位表的 CSV 同一套体验（支持中文逗号、制表符、`#` 注释、导出带 BOM）。性别接受 `男/女/M/F/male/female`。
- **🔑 批量生成密码**：给还没密码的同学（或全班）生成初始密码，位数可选 4/6/8/10/12，**默认 8 位**。生成后点「导出密码表 CSV」发给同学。
- **重置 / 隐藏 / 删除**：重置会作废该同学的密码；隐藏只是从广场上撤下来，数据还在。

真实姓名、性别、学号由管理员设定，同学自己改不了（空间里会标 🔒）。学号不填、性别不填都行，卡片上会显示灰色的「未设置」。

### 登录

广场标题栏右上角有「登录」按钮。登录框里先从**下拉框**里选自己（选项按学号排序，写着「昵称 · 真实姓名（学号）」；上面有个搜索框，支持中文和拼音首字母，比如 `cyn` 能搜到「车一诺」），再输密码。密码框下面有**数字小键盘**，触屏上不用调出系统键盘也能输。

**密码是纯数字，4–20 位，支持防窥功能**：输入内容里只要**包含**你的密码就能登录，所以可以在前后随便多打几个数字，旁边的人看不出哪几位才是真的。登录成功后输入框会立刻清空。

登录后标题栏的「登录」按钮会变成「头像 + 昵称 + 🏠 进入空间」，末尾的 `⌄` 里还有「修改密码」和「退出登录」。**关闭广场（以及个人空间）就会自动退出登录**——这是全班共用的机器，不留后门。

### 个人空间

点标题栏的「🏠 进入空间」，或者点广场上任何一张卡片（别人的空间是只读的）。左边是自己的卡片放大版，右边分三个标签页：

- **资料**：12 项信息一览。`✏️ 编辑资料` 可以改头像、背景图、昵称、生日、个性签名、个人介绍，编辑时左边卡片实时跟着变。
- **关注**：列出你关注的人，可以取关（要点两次确认，触摸屏上容易误触）。
- **粉丝**：列出关注你的人。没关注的显示「+ 关注」，已关注的显示「互相关注」和「取关」。

**互相关注**的标识只有互关的两个人自己看得到，第三个人打开你的空间是看不到的。

昵称**必须全站唯一**（登录列表就是靠它区分人的），1–12 个字；个性签名最多 30 字；个人介绍最多 200 字。

### 隐私与加密

打开 `data/plaza.json` 能看到什么，取决于字段：

| 数据 | 存储方式 | 谁能看到 |
|------|---------|---------|
| 昵称、头像、背景图、签名、介绍、真实姓名、性别、学号、关注/点赞关系 | 明文 | 本来就要投在班牌大屏上，全班可见 |
| 生日（展示开关**开**） | 明文 | 同上 |
| **生日（展示开关关）** | **AES-256-GCM 加密** | 本人登录后，或管理员解锁名单管理后 |
| 登录密码 / 管理员密码 | PBKDF2-SHA256 哈希 | 谁都看不到明文 |

关掉「在广场中展示我的生日」之后，生日会**加密**再存进文件，打开 JSON 只能看到一段乱码。用的是「数据密钥」方案：内容用一把随机密钥（DEK）加密，然后**用本人密码派生的密钥包一份 `own`、用管理员公钥（RSA-OAEP）包一份 `adm`**——所以本人和管理员都解得开，别人不行。

> **隐藏生日之前，管理员密码必须已经设好**，否则会拒绝并提示。因为第一次隐藏时要同时包出 `adm` 那一份，少了它这份密文将来谁都打不开。管理员在「设置 → 名单管理」里设一次就行；之后同学隐藏生日不需要管理员在场，也不需要再输管理员密码。

重置密码不会丢数据：管理员重置时用管理员私钥解出 DEK，再用新密码重新包一份 `own`，内容一个字节都不用动。改管理员密码也一样不会丢数据——所有人的 `adm` 是用管理员公钥包的，和密码无关，只需把管理员私钥用新密码重新加密一遍。

- 派生参数：PBKDF2-SHA256，每人独立 32 字节随机盐，200,000 次迭代；输出 64 字节切成两半，前 32 字节当 AES 密钥（**只在内存里，从不落盘**），后 32 字节存进文件仅用于验证密码。这就是所谓「密钥分离」。
- 存密码长度（`pwdLen`）是为了让防偷窥的包含式匹配只需试十几个窗口而不是两百个，登录才能压到 1 秒内。
- **强度上限就是密码强度**。6 位纯数字只有约 20 bit，一台游戏显卡几十秒就能穷举完；8 位约 33 分钟；10 位约 2.3 天。所以初始密码默认给 8 位，空间里也提示同学「想更好地保护隐藏的生日，建议用 10 位以上」。
- 隐藏的生日有两把钥匙：本人密码派生的密钥（解 `own`）和管理员的私钥（解 `adm`）。管理员重置某个同学的密码时会先用管理员私钥解出 DEK，再用新密码重新包一份 `own`，所以不会丢数据。

### 数据存储

`data/plaza.json` 存名单、关注、点赞和账号信息（约 25KB），`data/plaza_media.json` 单独存头像和背景图（压缩后约 3–6MB）。

拆成两个文件是必要的：`Store` 的写盘流程是「防抖 → 整体 PUT → 回读校验」，如果图片混在 `plaza.json` 里，每点一次赞都要传十几 MB。拆开之后点赞只写 25KB，秒回；而 `plazaMedia` **不注册 `Store.watch`**，4 秒一次的轮询也不会去拉它。

头像和背景图在前端压成 WebP（不支持 WebP 的老浏览器自动退回 JPEG）：头像裁成 256×256、≤ 40KB，背景图裁成 960×320、≤ 120KB。没上传头像的同学会自动得到一个「名字首字 + 渐变底色」的头像；**背景图不设就是纯白**，想要图的可以在「编辑资料」里上传，或直接从 9 张节气图里挑一张。

## 常见问题

**页面空白**：检查控制台报错、脚本路径。

**提示“本地服务未启动”**：运行 `LocalDataServer.exe` 后刷新。

**天气不可用**：依赖 `ipwho.is` 和 `open-meteo.com`，检查网络。程序会自动指数退避重试 3 次（2s / 4s / 8s）。

**每日 60 秒图片不显示**：两个图片接口都失败时会空白，不影响其他功能。

**金句不变**：检查“金句自动轮播”和“金句轮播间隔”设置；本地金句库为空时会提示“没有找到金句”。

**点击金句没反应**：需在设置中勾选“启用点击刷新金句”，默认关闭。音乐接管金句期间点击也不会切换。

**修改不保存**：本地服务未启动，启动后重试。

**找不到音乐**：确认 `data\music\` 存在且有音频文件（支持 mp3 / flac / wav / m4a / aac / ogg / opus / wma / ape / mp4）。

**音频设备切换失败**：需要以管理员身份运行 `LocalDataServer.exe`。

**虚拟时间点不了应用/恢复**：确认本地服务已启动，否则无法保存设置。

**广场里一个人都没有**：还没录入名单。去 **设置 → 名单管理** 里录入，或点「📄 从座位表导入」把座位表里的人名搬过来。

**登录框里某个同学是灰的**：他还没有初始密码。管理员在名单管理里「🔑 批量生成密码」后把密码发给他。

**关注 / 点赞点了没反应**：要先登录广场。未登录时会自动弹出登录框，登录成功后刚才那次操作会自动补上。

**忘了管理员密码**：手动删掉 `data/plaza.json` 里的 `admin` 字段，下次打开名单管理会重新要求设置。同学自己的隐藏生日都还在（`own` 那份不受影响），但管理员再也打不开旧的管理员副本（`adm`）——需要管理员重置这些同学的密码，让他们重填一次生日。

**管理员重置了某个同学的密码**：**不会丢数据**。重置时会用管理员私钥解出那把数据密钥，再用新密码重新包一份，隐藏的生日照样能看。

**隐藏生日时提示"请先让管理员设置管理员密码"**：第一次隐藏要同时生成一份管理员能解开的副本，所以必须先有管理员密码。到「设置 → 名单管理」里设一次即可，之后不需要管理员在场。如果提示的是"请管理员打开一次名单管理完成加密升级"，说明管理员密码是旧版本设的，管理员输一次密码就会自动升级。

**隐藏生日解不开了**：多半是手动删过 `admin` 字段、或者有人手动改了 `plaza.json` 里的 `secret` 字段——AES-GCM 是认证加密，改一个字节都会解密失败。修改管理员密码不会导致解不开。本人可以把这个开关关掉再打开，会重新生成一份。

**广场提示「当前是只读模式」**：本地服务没启动，改动不会被保存。运行 `LocalDataServer.exe` 后刷新。

**浏览器不支持加密**：`crypto.subtle` 缺失时（非常老的浏览器），「隐藏生日」的开关会被禁用，其余功能不受影响。现代 Chrome / Edge 都不会有问题。

## 开发

- 数据层放 `js/data/`，功能层放 `js/features/`，样式集中在 `css/style.css`（广场这一块单开 `css/plaza.css`，因为它自成一体、便于整体回退）；
- 模块挂载到 `window.App`，首字母大写，私有方法以下划线开头；
- 脚本加载顺序：数据 → 状态与工具 → 展示模块 → 模态框 → `main.js`；
- 新增 `.settings-modal` 会自动获得定时关闭功能；如需排除，将其 `id` 加入 `ModalTimer.EXCLUDE`；
- 所有涉及“当前时间”的业务逻辑都应使用 `window.App.Utils.now()`，不要直接 `new Date()`，否则虚拟时间会失效；
- 时间预览拖动过程中只做轻量刷新（`Utils.refreshAll`），松手后做完整刷新（`Utils.refreshAllFull`），避免高频 DOM 重建。

### 广场相关的约定

- 数据访问一律走 `App.Plaza`，不要在别的模块里直接改 `Store.get('plaza')`；改动之后调 `App.Plaza.save()`。
- **粉丝数、点赞量、互关状态都不落盘**，由 `following` / `likedBy` 现算。要加新关系时请沿用这个思路，别再存一份计数，否则迟早对不上。
- 任何用户输入进 `innerHTML` 前必须过 `App.Plaza.escape()`（就是 `Utils.escapeHtml`）。昵称、签名、介绍都是自由文本。
- 密码、`aesKey`、解密后的明文**绝不落盘**：`session` 只活在内存里，退出登录时 `App.Plaza.logout()` 会一起清掉。
- `plazaMedia` 不要注册 `Store.watch`——它是个几 MB 的大文件，订阅了会被 4 秒一次的轮询反复拉取。
- 需要「当前时间」时用 `App.Utils.now()`，不要用 `new Date()`（广场里用于「最近更新资料」排序）。
- 改 `App.PlazaCrypto.DEFAULT_ITERS` 会同时影响新凭据的派生和旧凭据的验证（旧记录里存着自己的 `pwdIters`，所以调大是安全的、不会让老密码失效）。
