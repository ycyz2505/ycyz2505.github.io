# 杨村一中电子班牌

面向班级希沃一体机展示的静态网页，包含班级信息、作息课表、高考倒计时、二十四节气、金句轮播、每日 60 秒新闻简报、公告、通知、寻物、计算器、音乐播放器、虚拟时间等功能。以 1920×1080 为设计基准，自适应缩放到不同分辨率。

## 技术栈

纯 HTML + CSS + JavaScript，本地存储使用 json（由本地服务读写磁盘）。

## 快速开始

直接双击 `index.html` 即可打开。此模式下：

- 所有展示功能正常；
- 修改不会被保存；
- 右上角提示“本地服务未启动”。

考虑到 C 盘会还原，因此本地数据未使用浏览器缓存进行存储，而是由位于 D 盘的 `LocalDataServer.exe` 进行中转，实现网页直接读写本地磁盘。请先运行该文件，再打开页面。页面会自动探测本地端口 `17632` 到 `17641`。

音乐功能还需要在 `LocalDataServer.exe` 同级目录下建立 `data\music\` 文件夹，把歌曲按子文件夹分类放进去（同目录内可放 `.lrc` 歌词与封面图，封面优先匹配 `cover`、`folder`、`front`、`album`、`封面` 等命名，否则将使用文件夹内第一张图片）。

## 功能一览

**展示**：时间日期、天气（当前温度）、当前课程、下节课、作息倒计时、今日课表、高考倒计时、节气时间轴、每日 60 秒、金句轮播。

**交互**：设置、金句选择、公告、更新日志、通知、寻物、今日课表临时编辑、虚拟时间、计算器、音乐播放器、座位表、模态框全屏、模态框定时关闭。

| 选项 | 说明 | 默认 |
|------|------|------|
| 金句自动轮播 | 按间隔自动切换金句 | 开启 |
| 显示每日 60 秒 | 右侧图片容器 | 开启 |
| 联网获取金句概率 | 联网与本地比例 | 50% |
| 金句轮播间隔 | 单位秒，1 到 600 | 15 |

| 金句动画效果 | 淡入淡出 | 开启 |
| 主题色随时间渐变 | 整站配色随节气流动 | 开启 |
| 自动刷新页面 | 每 15 分钟刷新 | 关闭 |

**虚拟时间**：在设置面板中点击“虚拟时间”进入独立模态框，可修改网站显示的日期与时间，时钟、倒计时、作息、课表、节气均按此计算。底部滑动条可拖动预览一年内不同日期的效果（拖动时轻量刷新，松手后完整刷新），点击“恢复系统时间”即可回到跟随系统。

**今日课表临时编辑**：修改仅当天生效，次日自动恢复原始课表。

**模态框定时关闭**：更新日志、公告、寻物、通知、虚拟时间、今日课表、计算器、音乐的标题栏右侧有定时按钮，可选 1/3/5/10 分钟或自定义秒数，时间到自动关闭。

**主题跟随节气**：整站主色、按钮、背景、边框等颜色会在一年中随二十四节气缓缓过渡（基于 OKLCH 色彩空间插值）。可在设置中关闭以回退到默认绿色主题。

## 音乐播放器

在计算器中连续输入某暗码即可打开音乐播放器。暗码在 `js/features/modal_music.js` 中的 `SECRET_CODE` 常量里修改。

- 歌曲来源为 `data\music\` 目录，通过 `LocalDataServer.exe` 读取；
- 歌曲列表保留原始目录层级，以树形结构展示，可折叠展开，分类文件夹右侧显示歌曲数量；
- 自动识别歌曲文件夹内的图片作为封面（优先匹配 `cover`、`folder`、`front`、`album`、`封面` 等命名），无封面时以 ♪ 字符兜底；
- 支持逐行与逐字两种 LRC 格式；
- 播放时把当前歌词同步显示到首页金句位置，暂停或停止后恢复原金句轮播；音乐接管金句期间，点击刷新与自动轮播暂时挂起；
- 无歌词文件时播放条显示“歌词缺失”，金句区不被接管、继续轮播；
- 播放模式：顺序 / 列表循环 / 单曲循环 / 随机，点击循环按钮切换；
- 音量条可拖动，音量图标可点击静音/恢复上次音量；
- 首页按钮区最右侧的“⏹ 关闭”按钮仅在选中歌曲时显示，点击即可停止播放、清空当前歌曲并恢复金句轮播。

**播放器设置面板**（点击右下角 ⚙ 打开）：

- **定时关闭**：可选 5/10/15/30 分钟、1 小时预设，或自定义秒数、指定时刻到点关闭；
- **输出设备**：列出当前系统的音频输出设备，可逐台启用/禁用。该操作需要以管理员身份运行 `LocalDataServer.exe`。

## 座位表

首页按钮区的“🪑 座位表”打开，含 **展示 / 编辑** 两种模式（标题栏右侧 ⛶ 可全屏）。页面分成左右两栏：**左边是座位区**（宽度只随模态框 / 窗口变化，打开面板、切换模式都不会移动），**右边是控制区**（模式切换、搜索、随机抽取、编辑工具、积木盒、快速生成与 CSV 面板）。屏幕上方是教室前侧（黑板 / 讲台），下方是教室后侧。

座位表是一张**固定的格子表**：位置从一开始就存在，编辑模式下每个空位显示一个“待决定”的虚框（展示模式下只显示人名块与讲台块，空位与过道保持占位但不再显示边框），往后你只需要决定每个位置放什么。全表共用同一个“每行格数”（编辑模式里可以 +/- 调整）。

### 三种块（积木）

| 块 | 占格 | 说明 |
|----|------|------|
| 人名块 | 横向 2 格 | 显示一个人名 |
| 过道块 | 1 格 | 两组座位之间的空当，展示模式下为纯空白 |
| 讲台块 | 横向 2 格 | 深色底、显示“讲台”，**位置任意**，放哪都行 |

### 编辑（积木盒拖放）

- **添加**：编辑模式右侧有“🧱 积木盒”，按住人名块 / 过道块 / 讲台块直接拖到左侧格子里；拖动过程中左侧会高亮将要放下的位置，放不下（没有连续空位）时不会落下；
- **拖动**：已放好的块也可以按住拖动、跨行移动；拖动中按 `Esc` 取消；
- **改名**：点击人名块就地输入，回车或点击别处保存，`Esc` 取消；
- **删除**：块右上角 `×` 把它变回“待决定”的空位；每行末尾的 `↑` `↓` `🗑` 可以整行上移 / 下移 / 删除；
- **每行格数**：工具条里的步进器全局增减列数（右侧还有块时会提示先挪走）；
- **工具条**：`＋ 添加行`（整行都是待决定空位）、`⚡ 快速生成`（按“行数 × 每行人数 × 每几人有条过道”批量生成空表，可选顶部加讲台）、`📄 CSV 导入 / 导出`、`🗑 清空`。

### CSV 导入 / 导出

一行 CSV = 座位表的一行，**第一行在教室最前方**（讲台一侧）；字段之间用英文逗号分隔（也支持中文逗号、制表符，可直接从 Excel / WPS 复制粘贴）。

| 写法 | 含义 |
|------|------|
| `张三` | 人名块（横向 2 格） |
| `-` | 过道块（1 格） |
| `讲台` | 讲台块（横向 2 格） |
| 空字段 | **待决定的空位**（1 格） |
| `_` | 空人名块（横向 2 格，还没有名字的座位） |
| `# 开头的行` | 注释，导入时忽略 |

```csv
# 示例：第一行讲台居中，下面一行 6 人、中间留一条过道
# 空字段 = 待决定的空位
,,,,,讲台,,,,,,
张三,李四,王五,-,赵六,钱七,周九
```

模态框进入“编辑”模式后点“📄 CSV 导入 / 导出”即可看到同样的教程与示例：可直接在文本框里编辑后导入、选择 `.csv` 文件导入、复制当前座位表、或下载 CSV（导出带 BOM，Excel 打开不乱码，文件名形如 `座位表-20261004-1536.csv`）。导入会自动替换当前座位表并把各行对齐到统一格数。

### 人名搜索

在展示模式的搜索框里每输入一个字符就即时高亮所有匹配的人名块，不需要按回车；右侧提示匹配人数。

- 中文前缀：输入 `车一` 可匹配“车一诺”；
- 拼音首字母：输入 `cyn` 可匹配“车一诺”，也支持混输（如 `车yn`）；
- 多音字（车、单、曾等）按全部读音匹配；
- 回车可滚动定位到第一个结果（并闪一下），`Esc` 或搜索框右侧 ✕ 清空。

### 随机抽人

点击“🎲 随机抽取”后连续随机高亮单人，**两次高亮的间隔先快后慢、依次拉长**（约 45ms → 300ms），**总时长 6 秒**；最后一次高亮的人就是抽取结果，随后弹出大号渐变姓名卡片（彩带 + 弹入动画），可“🔁 再抽一次”或“完成”；被抽中的座位在座位表中脉冲高亮，关闭弹窗后清除，抽取过程中按 `Esc` 可取消。

### 数据存储

座位表数据保存在 `data/settings.json` 的 `settings.seating` 字段，形如：

```json
{ "version": 2, "cols": 6, "rows": [[null, null, { "t": "p" }, { "t": "s" }, null, null], [{ "t": "n", "n": "张三" }, { "t": "s" }, { "t": "a" }, { "t": "n", "n": "李四" }, { "t": "s" }, null]] }
```

`cols` 是每行格数；每行是由格子组成的数组，格子取值：`null` 待决定的空位、人名块 `n`（占 2 格）、过道块 `a`、讲台块 `p`（占 2 格）、续格 `s`（2 格块的第二格，渲染时被块覆盖）。旧版（`version: 1`）的数据会在打开时自动迁移成这种格式。每次编辑操作都会自动写入本地；`js/data/pinyin.js`（汉字 → 拼音首字母表）随站点一起分发，搜索与抽取全部离线可用。

## 本地数据服务

页面通过 `LocalDataServer.exe` 读写本地磁盘，接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/ping` | 探测服务 |
| GET | `/api/list` | 列出数据文件 |
| GET | `/api/data/{name}` | 读取数据 |
| PUT | `/api/data/{name}` | 写入数据 |
| POST | `/api/data/{name}` | 写入数据 |
| DELETE | `/api/data/{name}` | 删除数据 |
| GET | `/api/music/tree` | 获取音乐目录树 |
| GET | `/api/music/media?path=` | 流媒体播放（支持 Range 请求） |
| GET | `/api/audio/devices` | 列出音频输出设备 |
| POST | `/api/audio/device` | 启用/禁用某台输出设备 |

支持的数据名称：`settings`、`timetable`、`schedule`、`phrases`、`solarterms`、`lostfound`、`notifications`。

服务不可用时自动降级为内存模式，刷新后修改丢失。

## 数据读取规则

大部分模块遵循：

```text
Store 缓存 > js/data 中的默认数据
```

写入时先更新缓存，150 毫秒防抖后提交到本地服务；页面关闭时立即写入待保存数据。

## 页面缩放

以 1920×1080 为基准，按视口宽度计算 `zoom` 比例，等比缩放到不同大屏。

## 常见问题

**页面空白**：检查控制台报错、脚本路径。

**提示“本地服务未启动”**：运行 `LocalDataServer.exe` 后刷新。

**天气不可用**：依赖 `ipwho.is` 和 `open-meteo.com`，检查网络。程序会自动指数退避重试 3 次（2s / 4s / 8s）。

**每日 60 秒图片不显示**：两个图片接口都失败时会空白，不影响其他功能。

**金句不变**：检查“金句自动轮播”和“金句轮播间隔”设置；本地金句库为空时会提示“没有找到金句”。

**点击金句没反应**：需在设置中勾选“启用点击刷新金句”，默认关闭。音乐接管金句期间点击也不会切换。

**修改不保存**：本地服务未启动，启动后重试。

**找不到音乐**：确认 `data\music\` 存在且有音频文件（支持 mp3 / flac / wav / m4a / aac / ogg / opus / wma / ape / mp4）。

**音频设备切换失败**：需要以管理员身份运行 `LocalDataServer.exe`。

**虚拟时间点不了应用/恢复**：确认本地服务已启动，否则无法保存设置。

## 开发

- 数据层放 `js/data/`，功能层放 `js/features/`，样式集中在 `css/style.css`；
- 模块挂载到 `window.App`，首字母大写，私有方法以下划线开头；
- 脚本加载顺序：数据 → 状态与工具 → 展示模块 → 模态框 → `main.js`；
- 新增 `.settings-modal` 会自动获得定时关闭功能；如需排除，将其 `id` 加入 `ModalTimer.EXCLUDE`；
- 所有涉及“当前时间”的业务逻辑都应使用 `window.App.Utils.now()`，不要直接 `new Date()`，否则虚拟时间会失效；
- 时间预览拖动过程中只做轻量刷新（`Utils.refreshAll`），松手后做完整刷新（`Utils.refreshAllFull`），避免高频 DOM 重建。
